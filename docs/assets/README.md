# Architecture assets

- `cover.png`: paper-style overview generated with the built-in ImageGen tool, then revised to separate outbound device commands from returning results. Prompt: `cover-prompt.txt`. No benchmark or publication claim is made.
- `architecture.svg`: editable source-mapped diagram generated by `scripts/draw_architecture.py` using the Python standard library.
- `architecture.png`: high-resolution raster export of that SVG using CairoSVG.

The author's reference images informed the visual style only and are not redistributed. Project-owned assets follow the repository's MIT license. The SVG is the preferred starting point for precise edits and reuse.
