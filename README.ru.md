# Reelsomet

**Система для самостоятельного размещения, которая связывает веб-панель, планировщик публикаций и Android-устройства.**

![Архитектура Reelsomet](docs/assets/cover.png)

Сервер хранит контент и расписание, отправляет команды по WebSocket, а Android-приложение выполняет действия через Accessibility и возвращает результат. В репозитории есть Python/FastAPI-сервер, Vue-панель, Kotlin-приложение, тесты и редактируемая схема архитектуры.

Лицензия — **MIT**: код можно использовать, изменять и включать в свои проекты с сохранением уведомления о лицензии. Активация и коммерческие ограничения количества устройств удалены.

## Запуск

```sh
git clone https://github.com/parlorsky/reelsomet-open-source.git
cd reelsomet-open-source
docker compose up --build -d
docker compose logs reelsomet
```

Откройте http://localhost:8000. Вставьте токен первой настройки из лога сервера, задайте пароль администратора и сохраните выданный токен устройства. Конфигурация и данные сохраняются в Docker volume.

Это экспериментальный выпуск исходников. Основной сценарий — Instagram; Pinterest и Reddit требуют дополнительной проверки. Работа на реальном телефоне зависит от версии Android и интерфейса установленного приложения.
