# Changelog

## 0.1.0 — 2026-10-07

Initial open-source source distribution.

- Combine the Python control plane, Vue dashboard and Kotlin Android client in one repository.
- Replace commercial activation with unrestricted MIT-licensed use.
- Add isolated local configuration, one-use first-run credentials and local-only default networking.
- Add container packaging, build instructions, contribution guidance and architectural figures.
- Remove production data, installation-specific endpoints, signing paths and proprietary key-generation code.

This is a source release. Target-app UI changes and phone-specific accessibility behavior require device validation.
